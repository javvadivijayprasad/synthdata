## Getting help

- **Questions / how-do-I** — open a
  [GitHub issue](https://github.com/javvadivijayprasad/synthdata/issues) with the
  `question` label.
- **Bugs** — open an issue with your schema, plan YAML, seed, and the exact
  command (see [CONTRIBUTING.md](CONTRIBUTING.md) for the template). Same seed =
  same output, so this makes the bug perfectly reproducible.
- **Security issues** — please do **not** open a public issue. Email
  <jvijayprasad@gmail.com> and allow a few days for a response.
